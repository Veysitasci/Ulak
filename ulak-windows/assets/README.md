# Assets

Bu klasör uygulama ikonlarını içerir.

- `icon.png` - PNG formatında uygulama ikonu
- `icon.ico` - Windows için ICO formatında ikon (eklenmeli)

Not: Gerçek bir .ico dosyası oluşturmak için online araçlar veya ImageMagick kullanabilirsiniz:
```
magick icon.png -resize 256x256 icon.ico
```
